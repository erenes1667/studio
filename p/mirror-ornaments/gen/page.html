    @@PRINT_CARDS@@

    Why PETG, not PLA, on a hot dashboard

    • It keeps its shape in the heat. A parked car in the sun heats the dashboard and the mirror. PLA goes soft first.
    • The slicer agrees. BambuStudio's own filament profiles set the softening point at @@PLA_C@@ C for generic PLA and @@PETG_C@@ C for Bambu PETG Basic.
    • It flexes before it cracks. An ornament swings and knocks the glass. PETG takes that better than brittle PLA.
    • Your brief asks for PETG. The files and the print notes are set up for it.
    Generic PLA@@PLA_C@@ C
    Bambu PETG Basic@@PETG_C@@ C
    Softening (vitrification) setting in the BambuStudio filament profiles for the P2S. It is a slicer setting, not a lab test of these prints.

    04 / Checks

    What I checked, file by file.

    Checked by script after the files were written, not by eye. The checker does not share code with the generator.

    @@CHECK_ROWS@@
    FileTrianglesVolumeClosed surfaceOverhang over 45 deg
    • Closed and clean. Every STL is watertight with consistent winding and positive volume (trimesh). The parts inside each 3MF match the STLs.
    • No overhang. Every wall is vertical. Each upper layer sits fully inside the layer below, so every face that points down is the plate or rests on another body.
    • Slicer agrees. With automatic supports switched on, BambuStudio made @@SUP_CAR@@ support toolpaths for the car and @@SUP_STATE@@ for the state, and used the same filament as with supports off.
    • Same files as the viewer. The 3D view above loads these STLs. It is not a render.
    • Made by code. Shapes in gen/shapes.py, meshes and 3MF in gen/make.mjs (three.js 0.160), checks in gen/qa_mesh.py. A change to a design is a rerun, not a redraw.
