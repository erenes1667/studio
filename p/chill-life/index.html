01

The system, as eight steps

Click a step. Each one shows the n8n nodes and the prompt outline behind it. Start with step four: it is the gate.

  1. Step 1 of 8

    Brand voice and product list

    One doc holds Beth's own words, a short list of guardrails, and the live product list. Every prompt in the system starts by reading it. Only Beth edits her words.

    n8n nodes
    • Schedule Trigger (nightly)
    • Google Docs (Get)
    • Shopify (Product: Get Many)
    • Edit Fields
    • Google Sheets (Update Row)
    Prompt outline
    Block A  Her words, verbatim, with the source line.
Block B  Guardrails: no claims, no stats, no discounts, no invented products or people.
Block C  Product list: name, handle, one-line description, link. Synced from Shopify, never typed by a model.
Block D  Pillars: positivity, mental fitness, healthier youth sports, tech-free breaks.
    The model cannot edit this doc. A change to Block A goes through the same approval step as a post.
  2. Step 2 of 8

    Weekly topic agent

    Reads last week's topics and last week's numbers, then plans five slots for the week. It rotates the four pillars so nothing repeats.

    n8n nodes
    • Schedule Trigger (Mon 07:00)
    • Google Sheets (Get Rows)
    • AI Agent
    • Anthropic Chat Model
    • Structured Output Parser
    • Split Out
    Prompt outline
    System  Voice doc (blocks A to D).
User    Week date. Last four weeks of topics. Last week's results rows, or "none".
Task    Plan five slots: day, format, pillar, angle, needs_product_link.
Rules   Cover all four pillars. Do not repeat an angle from the last four weeks. One plain sentence per angle. No invented facts.
Return  JSON only, checked by the parser.
    First run has no results to learn from, so the agent is told that in plain words instead of guessing.
  3. Step 3 of 8

    Drafts: posts, Reel scripts, emails

    Each slot gets its own call with a format prompt. A Code node then checks the draft against the guardrails before anyone sees it.

    n8n nodes
    • Loop Over Items
    • Switch (by format)
    • Basic LLM Chain x3
    • Anthropic Chat Model
    • Code (guardrail check)
    • Google Sheets (Append Row)
    Prompt outline
    System  Voice doc. "Write it to be edited, not published."
Post    Caption, at most 80 words, a visual note for Beth, at most four hashtags.
Reel    Hook, four beats (on-screen text plus voiceover), closer, short caption.
Email   Subject, preview text, body, one call to action.
Check   Code node rejects percent signs, dollar signs, em dashes, unknown product names, missing link token. Failed drafts rerun once, then go to Beth marked "needs a human".
    A draft that breaks a guardrail never reaches the approval step as if it were fine.
  4. Step 4 of 8

    Approval step

    Each draft lands in Telegram or in her inbox with three choices: Approve, Edit, Hold. One tap. Nothing moves past this step without it.

    n8n nodes
    • Telegram (Send and Wait for Response)
    • Gmail (Send and Wait for Response)
    • IF
    • Wait
    • Basic LLM Chain (apply edit)
    • Google Sheets (Update Row)
    Prompt outline
    Message  Draft text, visual note, where it would post, link preview. Marked: sample or real.
Approve  Status becomes approved, draft goes on.
Edit     Beth types one line. An LLM call changes only what she asked and sends the full draft back to her for a second look.
Hold     Status becomes held. It stays in the sheet.
Silence  Waits. After 48 hours it sends one reminder. It never approves on its own.
Edit prompt  "Apply this instruction to the draft. Change nothing else. Return the full draft."
    No timeout path leads to publishing. Silence means hold.
  5. Step 5 of 8

    Shopify product links

    A Code node swaps the link token for the real product URL and adds tracking tags. The model never writes a URL.

    n8n nodes
    • Shopify (Product: Get Many)
    • Code (build URL and UTM)
    • Edit Fields
    • IF (token missing)
    Prompt outline
    No prompt. Code only.
Token    {{PRODUCT_LINK}} in the approved draft.
Build    Product URL from the Shopify handle, plus utm_source, utm_medium, utm_campaign (week), utm_content (draft id).
Check    If the product is archived or out of stock, the draft returns to Beth instead of linking to it.
    A model cannot invent a link, because it never gets to write one.
  6. Step 6 of 8

    Scheduler

    Approved posts go to her scheduling tool at the time on the calendar. Emails are created as drafts in her email platform. Beth sends them.

    n8n nodes
    • Wait (until publish time)
    • Switch (by channel)
    • HTTP Request (scheduling tool or Meta Graph API)
    • HTTP Request (email platform draft)
    • Error Trigger
    • Telegram
    Prompt outline
    No prompt. Code and API calls.
Rule     Only rows with status approved and a link filled in can enter this step.
Posts    Sent to the scheduling tool Beth already uses.
Emails   Created as drafts. A human presses send.
Errors   Error Trigger tells me, the builder, in Telegram. Beth gets no alarm noise.
    Open question for Beth: which scheduling tool and which email platform she uses today. The step is built around her answer.
  7. Step 7 of 8

    Performance pull

    Pulls orders carrying our tracking tags from Shopify, plus post and email stats, and writes them into one sheet row per draft.

    n8n nodes
    • Schedule Trigger (Sun 18:00)
    • Shopify (Order: Get Many)
    • HTTP Request x2
    • Merge
    • Code (join on utm_content)
    • Google Sheets (Update Row)
    Prompt outline
    No prompt. Numbers go from each platform into the sheet as reported. No model rounds, estimates or fills gaps.
Join     utm_content equals draft id.
Gap      If a platform returns nothing, the cell says "no data", not zero.
    Empty is not zero. A silent platform shows as no data.
  8. Step 8 of 8

    Weekly digest to Beth

    One short message: what went out, what got clicks or sales, what Beth changed most, one idea for next week. It also feeds step 2.

    n8n nodes
    • Google Sheets (Get Rows)
    • Aggregate
    • AI Agent
    • Anthropic Chat Model
    • Gmail (Send)
    • Telegram
    Prompt outline
    System  Voice doc.
User    This week's rows from the sheet, including Beth's edit notes.
Task    Under 150 words. List what went out. Copy numbers exactly from the sheet. Name the edit Beth made most often. Suggest one change to the voice doc or one idea for next week.
Rules   Never write a number that is not in the sheet. A voice doc change is only a suggestion and goes through approval.
    The loop closes here: her edits and the numbers shape next Monday's topics.

Two weeks to launch

Week one

Voice, topics, drafts, first sample.
  1. MonKickoff call. Beth sends access: Shopify (read only), email platform, scheduling tool, a Telegram or email for approvals.
  2. TueVoice doc v1 from her posts, site copy and answers. She edits it. Product list syncs from Shopify.
  3. WedWeekly topic agent running in test. First plan for the week goes to her.
  4. ThuDraft prompts for posts, Reel scripts and emails. Guardrail check on every draft.
  5. FriFirst sample week goes to Beth. Her edits go back into the voice doc.

Week two

Approval, links, scheduler, flows, tracking.
  1. MonApproval step live in Telegram or email. Edit and Hold paths tested.
  2. TueShopify links with tracking tags. Scheduler connected to her tool.
  3. WedWelcome and post-purchase flows built as drafts in her email platform. She reviews them.
  4. ThuPerformance pull, tracking sheet and weekly digest.
  5. FriDry run of a full week with nothing published. Handoff doc: how to edit the voice doc, pause the system, read the sheet.

Week three

First real week, run live with Beth approving every item. I read her edits, fix the prompts, and hand her the first digest. Still inside the starter price.

What I need from Beth in week one
  • Anything that carries her voice: posts she liked, past emails, about page.
  • Shopify access, read only.
  • Which email platform and which scheduling tool she uses today.
  • Where approvals should arrive: Telegram or email.
  • Who may see a draft besides her.
  • Words and topics that are off limits.
